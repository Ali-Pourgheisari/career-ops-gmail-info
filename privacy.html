Privacy policy

Effective November 14, 2026

Scope and operator

This policy describes the personal Career Ops Gmail job-alert integration operated by Ali-Pourgheisari. It covers the Gmail importer and this public information website. Separately configured Career Ops features and third-party services have their own data practices.

Data accessed and purpose

With the account owner's authorization, the importer uses the Google Gmail API with the gmail.readonly scope. It reads matching job-alert messages, including message identifiers, sender and authentication headers, subjects, and bodies, to extract job URLs and available role, company, and location details. It checks the connected mailbox address during authorization to verify that the dedicated inbox was selected.

Although the importer targets job-alert emails, the Google permission can read the authorized mailbox. It does not grant permission to send, delete, or modify messages.

Storage and retention

OAuth credentials are stored in a private local configuration file on the operator's computer. Extracted job details, processed-message identifiers, deduplication checkpoints, and sync status are stored in local Career Ops files. Message contents are read during processing. Stored job records and checkpoints remain until the operator deletes them; there is no automatic retention deadline.

Sharing and Google API Limited Use

The importer communicates with Google to authorize access and retrieve messages. This information website does not receive Gmail messages, tokens, or local job records. Gmail access credentials and mailbox contents are not published to this site's GitHub repository.

The importer does not sell Google user data, use it for advertising, or transfer it to train generalized AI or machine-learning models. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your control

The account owner can revoke the integration through Google Account connections, disable the local scheduled importer, and delete local credentials, checkpoints, and extracted records. Revoking Google access stops future authorized reads but does not delete records already stored locally.

This website

The public pages are hosted by GitHub Pages and contain no added analytics, tracking scripts, or forms. GitHub may process normal hosting and request information under its privacy statement.

Contact and changes

Contact the operator through the repository issue tracker without posting private information. Updates to this policy will appear on this page with an updated effective date.
